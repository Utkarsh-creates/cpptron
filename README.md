# C++ Hand-Coded Perceptron

A modular, lightweight implementation of a single-layer perceptron built from scratch in C++, without external machine learning frameworks.

Designed with a focus on systems-level programming, static memory management, and modular architecture.


## Build & Run

Requires a C++17 compiler and CMake.

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

Run:

```bash
./build/cpptron
```
